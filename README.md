# Ubisoft API Docs (unofficial)

Community reference for Ubisoft Connect and ubi-services endpoints.

This is **not** an official Ubisoft product. Endpoints change without notice. Use them only against accounts you own, and stay within Ubisoft's terms of service.

## Local preview

```bash
npm ci
npm run docs:dev
```

Build:

```bash
npm run docs:build
npm run docs:preview
```
